# Generate UI

## 执行目标

- 直接完成用户要求的 UI 代码与必要样式。
- 保持最小改动，不顺手扩展交互、数据流或工程配置。

## 必须遵守

- 先读取完整且相关的上下文，再开始生成或修改 UI。
- 优先复用仓库内已有组件、结构、命名和样式组织方式。
- 以可读性和稳定性优先，不为“更通用”额外引入抽象。
- 只处理当前任务要求的界面范围，不顺手重构无关页面或样式。
- 用户没有明确要求联调、运行、截图或验收时，只交付代码改动。
- 生成完成后，不主动启动本地预览，不主动运行开发服务，也不使用内置浏览器检查实际排版。

## 执行提醒

- 如果任务同时涉及 Vue、SCSS、接口消费等内容，继续叠加对应 skill 约束。
- 如果用户明确要求预览、截图、联调或排查运行时样式问题，再进入本地运行和浏览器检查流程。
