# codex-skills

这个仓库用于集中管理我在 Codex 中使用的本地 Skills，目标是把常用开发约束和执行流程沉淀成可复用规则。

## codex个性化配置 设置 => 个性化 => 自定义指令

- 如果代码仓库中有 AGENTS.md 的话，必须严格按照这个文件优先级最高去执行
- 处理任何任务前，必须先判断命中的 skill，并读取对应 skill 内容。
- 只要任务涉及某个 skill 的适用场景，就必须遵循该 skill；不得因改动小、只读文件、只回答问题或只执行命令而跳过。
- 在未读取并确认相关 skill 约束前，不得开始分析、修改代码、运行命令或给出执行结论。
- 多个 skill 同时命中时，相关 skill 规则全部生效；如规则冲突，优先执行与当前改动最直接相关的 skill。
- skill 一旦命中，其 `SKILL.md` 中全部规则、流程、检查和交付条件默认全部执行；除正文明确限定且条件不成立的条款外，不得自行挑选或跳过。

## 仓库用处

- 统一管理前端开发中的核心规则（编码、最小改动、接口消费、样式、注释、提交规范等）
- 在不同项目间复用同一套技能约束，减少重复沟通与重复配置
- 让 AI 协作输出更稳定，减少“风格漂移”和无关重构
- 基于 Git 历史追踪每次 skill 的演进

## Skills 目录说明

每个 skill 目录通常包含：

- `SKILL.md`：skill 说明、适用场景、强制规则、执行提醒
- `agents/openai.yaml`：agent 侧配置

所有 skill 均采用强制完整执行模式：命中后默认执行文件内全部规则，并以命令式交付条件完成收口，不使用提问式自检代替实际检查。

当前已包含：

- `api`：接口请求与返回值消费规则，要求请求参数类型直接引用对应 API 目录下 `types.ts` 的定义，请求参数与返回字段均按必填处理，并以后端字段为准保留原始值与原始类型；不加兼容层、二次格式化或空值转换，不省略请求字段；接口文档标注为 `bigint` 的字段，前端 TypeScript 类型定义为 `string`，避免数值精度丢失；列表缺少展示字段时不额外请求补齐，展示占位文案按产品规则处理
- `comment`：代码注释规则，要求改动时同步补齐必要注释并按功能模块组织 template、script、type 注释
- `css`：SCSS 编写规则，强调合法嵌套、层级一致与现有样式结构延续
- `frontend-global`：仓库级全局规则，适用于任意文件改动，集中定义编码检查、最小改动、禁止无关重构、变更链路回查与残留清理等通用硬约束；类型检查、构建或测试通过不能替代完整调用链收口
- `generate-ui`：UI 生成规则，适用于页面、组件和静态界面开发，强调聚焦界面范围直接交付代码，默认不主动启动本地预览或浏览器验排版
- `git`：提交信息规则，基于 Conventional Commits 并结合仓库本地表述习惯，重点约束提交格式和范围表达
- `react`：React 组件开发规则，强制组件样式使用 `*.module.scss`，并要求嵌套盒子的 TSX/JSX DOM 结构与 SCSS 嵌套层级严格一一对应；同时约束 CSS Modules 的导入与使用、变更链路回查及无效样式和纯透传逻辑清理
- `vue`：Vue 3 + TypeScript 页面与组件开发规则，要求页面目录和名称使用首字母小写的 camelCase，公共及页面私有组件目录和名称使用首字母大写的 PascalCase，禁止使用横线或下划线，并统一采用“目录 + `index.vue`”结构；import、路由与自动注册路径必须严格匹配磁盘和 Git 索引大小写，Windows 上仅修改大小写时通过临时名称完成两段式重命名；同时强调 `.vue` 文件区块顺序、所有 `<style>` 块必须声明 `scoped`、响应式简化、组件默认配置去重和完整调用链检查；第三方组件二次封装必须通过 `$attrs` 显式透传主组件能力，对外可回写状态必须使用 `defineModel`，并清理失效的纯透传代码和兼容判断

## 使用方式

1. 将本仓库同步到你的技能目录（或作为统一规则源）。
2. 在执行任务前匹配命中 skill。
3. 完整执行目标 skill 的 `SKILL.md` 中全部规则、流程、检查和交付条件。
4. 如有多个 skill 同时命中，叠加执行全部命中规则。

## 维护约定

- 新增 skill 时，补齐对应的 `SKILL.md` 与 `agents/openai.yaml`
- 修改 `skills/*` 内容时，同步更新 `README.md` 中对应 skill 介绍
- 具体同步要求见仓库根目录 `AGENTS.md`
